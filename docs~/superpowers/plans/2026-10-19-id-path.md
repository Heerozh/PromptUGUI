# `@id` 认路径；`click@` 可以指向模板实例 — Implementation Plan

> **For agentic workers:** 按 Task 顺序执行，步骤用 checkbox（`- [x]`）跟踪。每个 Task Red 先行。
> 设计依据：`docs~/superpowers/specs/2026-10-19-id-path-design.md`（下称 spec）。2026-10-19 与作者对齐（IP-D1…D5 按推荐）。

**Goal：** 所有 `@id` 认 `a/b` 路径；`click@x` 在 x 不是 `<Btn>` 时用 x 里唯一的 `<Btn>`；`<Popover>` 此时挂在 x 上。

**Architecture：**
- `TriggerSourceResolver.ResolveId`：首段走原有的词法查找，后续段查 `ScopedIds`。所有 `@id` 都经过它，一处改动全部生效。
- 回退集中在 `ClickBtnOf`，由 `FindBtn`（Trigger）与 `FindClickSource`（Popover）共用。
- `Popover` 分开记录锚点（`_triggerAnchor`）与点击来源（`_trigger`）。
