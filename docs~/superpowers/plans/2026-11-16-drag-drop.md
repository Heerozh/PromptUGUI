## Context

今天只有 `<ScrollList reorder>` 能拖，且只在本列表里插入排序。要做的是任意控件拿起、放到别的控件上（九宫格阵形里换位、背包 → 装备槽），
跨容器、跨 Screen，触屏长按与外层滚动不冲突，拖动中结构变化干净取消。踩坑表见 spec §2。

**Goal：**
- 五个通用属性 `drag` / `drop` / `dragHold` / `dragHandle` / `dragDuration`；
- 拖源原地抬层（嵌套 Canvas）、跟手、松手先复位再发事件再 FLIP 飞行；
- 落点 = `RaycastAll` 最上层命中向上找，目标只在武装期可命中；
- 源一侧 `lift` / `drop` 推广到拖源；目标一侧 `drop-armed` / `drop-disarmed` / `drop-over` / `drop-deny` / `drop-out` / `receive`；
- C#：`UI.Drag`、`IControl.DragData` / `CanDrop`、`Control.OnDrop`、`DragInfo` / `DropEvent`；
- 取消矩阵、自动滚动、Carousel autoplay 暂停；
- lint 七条、XSD、skill、示例。

**Architecture：**
- **共享件（M0，从 `ReorderDriver` 抽出）**：
  - `LiftGesture`：phase 机（Idle / Pressed / Armed / Dragging / Scrolling / Swallow）、hold、设备轮询判松手（`PressedProbeForTests` 搬到这里，`ReorderDriver` 留转发属性）、`IsTouch`、转发；宿主通过 `LiftGesture.IHost` 决定按下是否可拿、何时拿起、跨轴是否立即拿起。
  - `FlowPlaceholder`：建 / 复制几何 / 摘除。
  - `EdgeAutoScroller`：视口边缘自动滚动的纯计算 + 写 Content。
  - `LiftLook`：默认 ×1.03 外观，相对拿起时的 `localScale`；换目标时先把上一个补间收尾。
  - `ReorderRowMarker` 改名 `LiftMarker`（lift / drop 信号 + `<Show on="lift">` 注册），拖源与列表行共用。
- **拖放（M1/M2，`Controls/Internal`）**：
  - `DragSource`（拖源控件自己 GO 上的组件）：uGUI 拖动接口 → `LiftGesture`；外层滚动容器识别与跨轴判定；`LiftMarker` 同 GO。
  - `DropTargetMarker`（目标控件自己 GO 上）：kinds、armed / over / deny 状态、六个信号、`<Show>` 注册、会话期命中。
  - `DragSession`（静态）：注册表、拿起（出流 + 抬层 + 武装）、每帧（跟手 + 自动滚动 + 悬停 + 自检）、松手（复位 → 事件 → 结算飞行）、取消；全局 runner（Play 模式隐藏 GO）；测试缝 `TickForTests` / `HitTestForTests`。
  - `LiftLayer`：抬层 Canvas 的加 / 复制设置 / 摘。
  - `SettleFlight`：FLIP 飞行（位置 + 缩放），飞行期抬层，按 RectTransform 去重，`Complete`。
  - 标记的生成时机：`ScreenInstantiator` 在 `AttachTo`（与 scale wrapper）之后，按 IR 声明（base 或任意 variant 写了 `drag` / `drop`）给控件 GO 加 `DragSource` / `DropTargetMarker` —— 后代挂钩在 DFS 后序 apply 里先于祖先的 setter 解析，标记必须先在（同 `ScrollListContentMarker` 的理由）。setter 兜底（C# 写 `DragKind`）。
- **命中**：`Control` 新增 `SetDragHit(persistent, session)` → 虚方法 `ApplyDragHit(bool want, bool overrideAuthored)`：
  - 基类：自身 GO 无 Graphic → `HitCatcher`（不要时销毁，避免挡住以后要加的 Graphic）；有 Graphic → 记原值、置 true、还原。
  - `Frame`：走面板 catcher（`Panel.SetRaycastTarget`），与作者声明合并。
  - `Image` / `RawImage` / `Text`：`RaycastIntent` 增 `DragSource`（常驻，作者 false 赢并告警）与 `Session`（临时，盖过作者 false）两个输入。
- **取消挂点**：`Screen.ReSolve` 开头、`PopupChain.DismissUnder`（关屏、行换项）、`PopupChain.DismissBelow`（新层）、`Control.ReleaseSubscriptions`（重绑 / 销毁，兜底）、`ScrollList` 的 Rebuild / ClearSlots / Dispose 开头（与 `_reorder?.Cancel()` 同处）、`TabGroupCore` / `Suggestions` 的重建入口、`EscapeChain` 新一环。
- **公开面**：`UI.Drag`（`Application/UI.Drag.cs`）；`DragInfo` / `DropEvent` / `DragResult`（`Controls/DragInfo.cs`，命名空间 `PromptUGUI.Controls`）。

**Tech Stack：** Unity 6 / C# 9；uGUI（Canvas overrideSorting、GraphicRaycaster、EventSystem.RaycastAll、LayoutElement.ignoreLayout）；LitMotion；R3；Input System（设备轮询，沿用 reorder）。
