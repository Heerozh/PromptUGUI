# `<Pages>` 互斥子视图容器（PGS）Implementation Plan

**Goal:** 新增 `<Pages selected="…">`：直接子节点即页、同一时刻只有 `selected` 那页 active；`selected` 是运行期独占
状态；`Tab.bind` 放宽到任意控件；`IScreen.FindAll<T>()` 给预览工具列 `<Pages>`。交付验收：宿主 Planet.ui.xml 的
`pageBuild` 改成 `<Pages>` 后 UI Preview 只见 `slotsView`，C# 用 `Show("newView")` 切换，横竖屏 ReSolve 不打回。

**Architecture:** `Pages : Control`（纯容器，无组件）；`Selected` setter 校验 + reconcile（Open 期停用走
`Screen.DeferDuringOpen`）；`BuiltinPrimitives` 以 `runtimeStateAttr: "selected"` 注册，`PeekRuntimeState` 回读；
lint 五条在 `Core/Lint/PagesRules.cs`（纯 C#，CLI + 运行时共用）。

**Tech Stack:** Unity 6 / C# 9.0、uGUI、R3（`Subject<string>`）。无新增包。

需求依据：`docs~/superpowers/specs/2026-09-17-pages-design.md`（下文 §n 指该文档）。决策 D1–D9 全部取推荐项。

## Global Constraints

- **分支**：`feat/pages`。**绝不提交到 main。**分步提交：每个 Task 一个 commit。
- **LangVersion 9.0**、**不用 System.Threading / Task**、**Core 纯 C# 子集**（`PagesRules.cs` 不 `using UnityEngine`）。
- **lint**：每个 Task 收尾 `cd .lint && dotnet format --verify-no-changes --severity warn PromptUGUI.Lint.slnx`。
- **CLI 编译守门**：Task 3 之后 `dotnet run --project .lint/UIXmlLint -- Runtime/Resources/`。
- **同 PR 必改 SKILL**（英文）：Task 5。
- **测试只经 Unity MCP 跑**（连着的是 ssw_re_client 宿主）；外部新建 `.cs` 后 `refresh_unity(mode="force",
  scope="all")`，等编译完成（~15 s）再 `read_console` / `run_tests`；判绿必核对 `summary.total`。
- **Red first**：每个 Task 先写失败测试，再写实现。
- **零回归守门**：`TabBarTests` / `BtnContentSizingTests` / `BuiltinTagsTests` / `PureContainerVisualAttrRulesTests` /
  `RaycastRulesTests` / `IRWalkerTests` / `XsdGeneratorTests` 每个 Task 后全绿；收尾跑整套 EditMode + EditorOnly。

**RUN(ClassName)**：`refresh_unity(compile="request", mode="force", scope="all")` → 等编译 → `read_console(types=["error"])`
必须为空 → `run_tests(mode="EditMode", assembly_names=["PromptUGUI.Tests.EditMode"], group_names=["ClassName"])` →
`get_test_job` 轮询。
